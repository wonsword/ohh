프로젝트 요약

법무법인 오현의 멀티사이트 CMS 구축. 한 번 데이터를 입력하면 28개 사이트 전체에 동기화되는 OSMU(One Source Multi-Use) 구조.

v3.0 변경: 「홈페이지 개발」 PDF의 모든 admin 요구사항 반영. 사이트 유형 3종(허브/민형경/기타)으로 분리, 메인 섹션 11개 슬롯 상세화, 상담 이메일 시스템·구성원 마크·팝업·우측 CTA 등 신규 기능 추가.

🏗 사이트 구성

  • 허브 사이트 1개 (통합 진입점·어그리게이터)
  • 그룹 사이트 26개 (분야별, 유형 2종으로 분리)
  • 관리자 사이트 1개 (어드민 CMS)
  • = 총 28개 사이트

⚡ 기술 스택

  • Web: Next.js 14+ (App Router, SSG/ISR)
  • Admin API: NestJS + Prisma
  • DB: PostgreSQL (AWS RDS Seoul)
  • 방어: Cloudflare (DDoS·WAF·캐시)
  • 저장소: AWS S3 / Cloudflare R2
  • Monorepo: Turborepo

🛡 보안 아키텍처

  • Cloudflare 방어층 + 한국 데이터 주권
  • 스팸봇 자동 차단 (Google·Naver·AI 크롤러는 허용)
  • 어드민 보호 → Cloudflare Access (이메일+OTP)
  • 오리진 보호 → Cloudflare Tunnel (인바운드 0)

📐 핵심 설계 원칙

  • 사이트 유형 3종 템플릿 (허브 / 민형경 / 기타)
  • 변호사 = 글로벌 마스터 (N:M, 사이트별 우선순위)
  • 업무사례 = 다중 사이트 동시 송출 (OSMU)
  • 한 번 입력 → 모든 사이트 자동 동기화

역할 정의 (5개)

👑 SUPER_ADMIN

  • 전 사이트·전 콘텐츠 모든 권한
  • 사용자·역할 관리 + 시스템 설정
  • 스팸봇 정책 + 캐시 관리
  • 예: 시크릿에이 운영 담당, 오현 IT 책임자

🌐 SITE_ADMIN

  • 담당 사이트(들)의 모든 권한
  • 해당 사이트 콘텐츠 발행·수정
  • 분야 그룹 운영자에 적합

✏️ EDITOR

  • 콘텐츠 작성·수정
  • 발행은 SITE_ADMIN 승인 필요
  • 마케팅·콘텐츠 작성자

👨‍⚖️ LAWYER (NEW · PDF 34p)

  • 본인 칼럼·인사이트 작성·수정
  • 본인 프로필 일부 편집 (사진·약력 추가)
  • 다른 변호사 콘텐츠 X

👁 VIEWER

  • 조회만 가능 (감사·외부 자문)
